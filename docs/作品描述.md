# 小宇宙桌面版作品描述

小宇宙桌面版是一款面向 macOS 用户的非官方 Chrome 扩展，将播客发现、搜索、订阅、节目详情和播放整合到独立桌面窗口中。用户可以查看单集、控制播放进度与倍速、复制节目或单集链接，并将音频保存到浏览器下载目录或指定的绝对路径。

作品打通了“收听—转写—总结—归档”的内容处理流程。ASR 可选择本地 Qwen3-ASR、Qwen API 或豆包 API，转写结果保存为 Markdown；AI 总结兼容 Qwen、豆包、DeepSeek、Kimi 和 GLM，支持 Prompt 版本管理、长文本分段总结及独立目录。点击“AI 总结”时，系统会判断是否已有转写稿，缺失时先执行 ASR，再生成结构化总结。

项目的创新在于兼顾模型兼容与隐私控制。Native Host 解决了浏览器无法写入绝对路径的问题，并将 API Key 保存到 macOS Keychain。本地 ASR 使用按任务启动的 Worker，完成后退出释放内存，不常驻后台，也不自动回退云端；使用云端服务前会提示数据外发和费用。作品还为长播客适配异步转写协议，自动补全模型接口路径，让用户建立稳定、可控的播客知识整理工作流。
